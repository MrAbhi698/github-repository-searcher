GitHub Repository Searcher
● Backend Application

Discover. Search. Store.

A Spring Boot REST API application that searches GitHub repositories, stores repository information in PostgreSQL, and retrieves results using powerful filtering and sorting options.

Explore API Documentation →

API Endpoints

Explore the core functionalities of the application.

POST

Search GitHub Repositories

/api/github/search

Search GitHub repositories by query, programming language and sorting preference. Repository details are saved in the PostgreSQL database.

GET

Retrieve Stored Repositories

/api/github/repositories

Retrieve saved repositories using language filters, minimum star counts and sorting by stars, forks or last updated date.
